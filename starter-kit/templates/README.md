# Tracking PHP Template Gate

Place the exact, clean, company-approved PHP tracking source in this directory only after it has been supplied and reviewed.

The final packaging task will read that source into the generated `index.php` `<head>`, validate its PHP syntax, and verify it appears exactly once. Do not create a substitute snippet from the documentation or copy the escaped chat version.

Required before this template can be added:

1. Canonical raw PHP source from the company.
2. Confirmed deployed `includes/store-tracking.php` path and host behavior.
3. Approved staging process to confirm one PageView and no `dead_store_tracking` marker.
